# Hackathon Details & Information

This directory consolidates all official hackathon problem statements, prompt briefs, and generated executive summary reports for the **Nexora Hackathon (Team Brocode)**.

## Contents

| File | Description |
| :--- | :--- |
| **[`nexora_Hackathon_Problem_Statement.pdf`](./nexora_Hackathon_Problem_Statement.pdf)** | Official hackathon challenge problem statement and evaluation rubric. |
| **[`Nexora_Brocode_Project_Summary_Report.pdf`](./Nexora_Brocode_Project_Summary_Report.pdf)** | Full comprehensive PDF submission report covering architecture, scoring math, test metrics, and bonus features. |
| **[`Project_Summary_1Page.pdf`](./Project_Summary_1Page.pdf)** | Single-page executive summary sheet optimized for rapid judges' review. |
| **[`summary.pdf`](./summary.pdf)** | Executive summary report alias. |
| **[`generate_summary_pdf.py`](./generate_summary_pdf.py)** | ReportLab Python script to programmatically compile the comprehensive multi-page summary PDF. |
| **[`generate_1page_summary_pdf.py`](./generate_1page_summary_pdf.py)** | ReportLab Python script to compile the concise single-page executive sheet. |

## Quick PDF Compilation
To re-generate the PDF reports:
```bash
python generate_1page_summary_pdf.py
python generate_summary_pdf.py
```
